# SentinelWeb
SentinelWeb is an AI-based hybrid web security framework that detects, analyzes, and prevents multiple web attacks including SQL Injection (SQLi), Cross-Site Scripting (XSS), and Prompt Injection.

##Features

i) SQL Injection Detection
ii) XSS Detection
iii) Prompt Injection Detection
iv) Adaptive Risk Analysis
v) Request Blocking 
vi) Security Dashboard 
vii) Attack logging
viii) Security Reports
ix) Hybrid Detection (rule based with ML)

BACKEND: FastAPI 
FRONTEND: React + Vite
ML: Python and scikit-learn
